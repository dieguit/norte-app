# Domain Docs

Read `CONTEXT-MAP.md` before exploring; it identifies the relevant context-specific `CONTEXT.md` files. Read relevant system-wide ADRs in `docs/adr/` and context-scoped ADRs in `<context>/docs/adr/`.

If these files do not exist, proceed silently. Create them only when `/domain-modeling` resolves terminology or decisions.

Use terms defined by the applicable context's `CONTEXT.md`. Explicitly flag conflicts with existing ADRs.
